# KOD Site

Сайт пространства KOD: страницы услуг и направлений, описания мероприятий, контакты и заявки. Данные о контенте управляются через отдельную CMS.

## Стек

- **Frontend**: React SPA, JavaScript, CSS‑модули и глобальные стили
- **Backend**: Strapi CMS (Node.js) в `kod-site-strapi`
- **API**: REST‑эндпоинты Strapi, клиентская обвязка в `src/api/`

## Функционал

- лендинги направлений и услуг
- страницы мероприятий и тематических программ
- интерактивный календарь событий с отдельными ссылками на каждое событие и наполнением из админки
- блоки с галереями, медиа и описаниями
- формы заявок/обратной связи
- статические документы (оферта, политика и т.п.)

## Структура

- `src/` — клиентское приложение (страницы, компоненты, стили)
- `public/` — статические ассеты
- `kod-site-strapi/` — CMS с моделями контента и админкой
